アプリ一般権限

API を初めて呼ぶと権限ダイアログが出ます。拒否した権限は設定 → アプリの権限 で変更できます（変更するとこの表も更新されます）。自分の /data/data/<id> は権限なしで使えます。

Root 権限（SuperSU）

HTML アプリ、または同一オリジンの iframe アプリが su.request() で root を宣言できます。許可されるとシステムアプリと同じ権限になり、/ 以下にもアクセスできます。

…

root なしで実行すると、/system・/data・書き込み系は ✗（permission denied）になります。

通知 API

コントロールセンター（ステータスバーをタップ）に表示されます。初回は「通知」権限の確認が出ます。通知をタップするとこのアプリが開きます。

API ランナー

チップを選ぶとメソッドと引数（JSON 配列）が入ります。編集して実行できます。<self> は自分のアプリ ID、<last> は install したアプリの ID に置き換わります。

ファイルピッカー / アプリで開く

ピッカーで選んだファイルは権限なしで受け取れます。ファイルアプリでテキスト・画像・json をタップして「アプリで開く」→ このアプリを選ぶと、ここに届きます。

一括テスト

安全な API を順番に呼びます。権限ダイアログが出た場合は許可/拒否を選んでください。
